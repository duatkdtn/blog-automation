[ 3. GitHub Actions 인증 방식 전면 개선 ]
문제: token.pickle이 만료/충돌되어 GitHub Actions 발행 실패 반복
원인: get_google_credentials()가 token.pickle만 사용, GOOGLE_TOKEN 환경변수 무시

해결:
- get_google_credentials() 수정
  → GOOGLE_TOKEN 환경변수 있으면 refresh_token으로 직접 인증
  → 없으면 기존 token.pickle 방식 유지 (로컬 사용 시)
- auto_publish.py restore_token() 제거
  → 기존: base64로 token.pickle 복원 시도 → 실패
  → 변경: get_google_credentials()가 직접 처리하므로 불필요
- auto_publish.py setup_env()에 GOOGLE_CLIENT_ID/SECRET 추가
- auto_publish.yml에 환경변수 추가:
  GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET

GitHub Secrets 추가 목록:
  GOOGLE_TOKEN       ← refresh_token 값 (get_refresh_token.py로 추출)
  GOOGLE_CLIENT_ID   ← Google OAuth 클라이언트 ID
  GOOGLE_CLIENT_SECRET ← Google OAuth 클라이언트 시크릿

[ 7. 블로그 조회수 분석 및 개선 계획 ]

▶ 발견된 문제 3가지

문제1. 제목이 매날 똑같은 말로 끝남
- 현재: 하루 8개 중 5~6개가 "총정리"로 끝남
  (총정리, 완벽정리, 핵심만 → Claude한테 이것만 쓰라고 시켜놔서 생긴 문제)
- 수정 예정: keyword_email.py 제목 생성 프롬프트에서
  "총정리/완벽정리/핵심만" 고정 목록 삭제
  → "자연스럽고 다양하게, 같은 표현 절대 반복 금지" 로 변경
- 예시 비교:
  지금: "ISA 계좌 단점과 중도해지 불이익 직장인 핵심만 총정리"
  바꾸면: "ISA 계좌 만들기 전에 이것만큼은 알고 가세요"

문제2. 같은 키워드 글이 반복 발행될 수 있음
- 현재: 정부지원금/정책자금은 중복 방지 있음 (used_gov/policy_keywords.txt)
  그런데 Claude가 매일 고르는 메인 6개 키워드는 중복 방지 없음
  → 다음주에 또 "ISA 계좌" 글 나올 수 있음
- 수정 예정:
  발행할 때마다 used_main_keywords.txt에 키워드 저장
  → 60일치 기록 유지, Claude한테 전달해서 비슷한 주제 제외

문제3. 하루 8개 너무 많음
- 현재: 8개/일 (정부지원금1 + 정책자금1 + 메인6)
- 수정 예정: 4개/일 (정부지원금1 + 정책자금1 + 메인2)
  발행 시간: 06:00 / 09:00 / 15:00 / 20:00 (4번으로 줄이기)
  → keyword_email.py PUBLISH_TIMES 수정
  → auto_publish.yml cron 8개 → 4개로 줄이기
  → 이메일 제목도 "오늘 자동발행 4개"로 변경

▶ 수정 예정 파일
- keyword_email.py (제목 프롬프트, PUBLISH_TIMES, best6→best2)
- auto_publish.yml (cron 8개→4개)
- auto_publish.py (발행 시 used_main_keywords.txt에 키워드 저장 추가)
